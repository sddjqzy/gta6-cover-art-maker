Vice Cover — a multi-panel GTA 6 cover art maker. Design your own Vice City-style cover in the browser: pick photos, a caption and tagline, a panel layout (trio, quad, duo), a color grade (sunset, neon, teal), and a size (square, portrait, wide), then export the finished cover.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 to try it in desktop Chrome.
